# Audio assets

The project bundles **no audio files**. Every `AmbientAudioManager` hook (`scripts/autoload/ambient_audio_manager.gd`)
is an unassigned `AudioStream` that plays nothing, except Rest Mode's ambience (D-62, R4), which falls back to a
temporary technical placeholder generated in code.

## Rest Mode ambience — `AmbientAudioManager.rest_ambience`

| | |
|---|---|

### Attempt to obtain a licensed recording (2026-10-14)

A properly licensed nature recording for the Pond Rest Spot was sought. The session's network policy refused every
candidate source (`commons.wikimedia.org`, `upload.wikimedia.org`, `freesound.org`, `opengameart.org`: HTTP 403 on
CONNECT), so nothing was downloaded and no unverified substitute was used. To fetch one, allow the source host in the
environment's network settings (or add the file to the repository by hand) and follow the requirements below.

### Requirements for the real recording

- **Character:** a gentle, seamless outdoor ambience for a pond edge — soft breeze, leaves, distant birds, a little
  water where it fits. Restrained and comfortable for repeated listening: no harsh noise, no sudden loud events, no
  dramatic effects, no distracting foreground sounds (D-48, D-50, D-55).
- **Technical:** a loop without an audible seam, long enough that repetition is not obvious (about 30–60 s or more);
  OGG Vorbis; mono or stereo; normalised so that the existing −14 dB playback level is comfortable — adjust the level
  (`REST_AMBIENCE_DB`) only on listening evidence.
- **Licence:** CC0 preferred; CC BY acceptable with its attribution recorded here and shown where the project credits
  third parties. Never a file whose source, author or licence cannot be established. Record, in a new row below: the
  file path, title, author, source URL, licence and its URL, attribution text, the date obtained and every
  modification (trim, loop, gain, format).
- **Integration:** put the file under `assets/audio/` and give the export a default
  (`@export var rest_ambience: AudioStream = preload("res://assets/audio/<file>.ogg")` — the manager is a script
  autoload, so there is no scene to assign it in). The fades, mute and single playback need no other change. The
  checker's R4 contract currently requires **no audio files** in the project; adding the recording updates that rule
  deliberately (allow exactly this file, with its row here).
